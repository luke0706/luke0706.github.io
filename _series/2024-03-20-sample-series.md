# Python 기초 시리즈 - 1편

이것은 Python 기초 시리즈의 첫 번째 포스트입니다.

## Python이란?

Python은 배우기 쉽고 강력한 프로그래밍 언어입니다.

### 주요 특징

- 간결한 문법
- 다양한 라이브러리
- 크로스 플랫폼 지원

## 기본 문법

```python
# Hello World 출력
print("Hello, World!")

# 변수 선언
name = "Python"
version = 3.9

# 조건문
if version >= 3.9:
    print(f"{name} {version} 버전입니다.")
else:
    print("이전 버전입니다.")
```
